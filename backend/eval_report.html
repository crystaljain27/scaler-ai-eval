03 · Discovered Failure Modes

01
Webhook Name Collision (Silent Failure)
Root Cause
Vapi passed the attendee's name parameter, colliding with Express server's req.body.name check.
Fix Applied
Prioritized req.body.functionName over req.body.name in the Express router for accurate tool routing.
02
Double Booking Race Conditions
Root Cause
Multiple recruiters hitting booking endpoints simultaneously caused slot collisions in the JSON file.
Fix Applied
Handled transactions synchronously inside a locked file-writing handler in calendarService.
03
Voice Barge-In Dialogue Clashes
Root Cause
Bot talking over user statements due to low speech-detection thresholds.
Fix Applied
Fine-tuned Vapi's end-of-speech detection settings and enabled immediate playback cancellation.
